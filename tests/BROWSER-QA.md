# 浏览器验收记录

日期：2026-10-25。使用真实浏览器打开本地 HTTP 预览，以下为本轮实测结果。

## 已通过

- 全屏入口「进入博客」跳转到独立 `/blog/` 文章列表。
- 文章卡片打开原 `/2025/10/27/hello-world/`；文章目录跳转到 `#Quick-Start`；面包屑及返回链接指向文章列表。
- 文章搜索：输入不存在的内容显示 0 篇及空状态；清空恢复；Hello 命中唯一真实文章。
- 个性化设置：切换深色主题与森林壁纸，关闭团子与界面动效；刷新后仍保留。
- 恢复默认偏好正常；主题选择具有当前选中状态。
- 音乐：点击后播放真实本地 WAV，按钮变为暂停；暂停、进度滑块、音量滑块、选择第二首均正常。
- 团子点击显示问候消息。
- 390px 和 320px 的窄屏布局实看：入口、菜单、资料卡、文章列表、阅读正文均能使用；手机菜单点击后收起。
- 1440px 桌面布局实看：横幅、左侧资料与纵向导航、右侧横向封面文章卡片、毛玻璃背景。

## 验证范围

窄屏与桌面宽度通过同源 iframe 的独立视口验证，不代表真实 iOS/Android 设备验收。浏览器已确认音源加载、播放状态与进度变化，未进行外部扬声器听感验收。没有推送或触发远端 GitHub Pages 部署；线上状态尚未验证。

自动测试运行 `npm test`，构建与链接检查运行 `npm run build`。原文章正文另以从原提交提取的 SHA-256 校验。
