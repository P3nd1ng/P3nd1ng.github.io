# 手动写文章和发布

自己创建 `.md` 文件，按年份、月份放在 `articles/` 下，例如：

`articles/2026/10/2026-10-28-我的一次旅行.md`

文件名必须以日期开头，后面可以用中文文章名。日期决定文章发布时间和归档，文件名决定网址；发布后不要随意改文件名。

文章开头只填写三个设置，然后空一行写正文：

```markdown
标题：我的一次旅行
分类：生活,旅行
封面：/img/articles/my-trip.webp

这是文章第一段。

## 一路见闻

这里继续写正文。
```

- 标题：网站显示的文章标题。
- 分类：可以填写多个，用英文逗号、中文逗号或顿号分隔；网站会按这些标签筛选文章。
- 封面：图片放在网站根目录 `img/articles/`，这里填 `/img/articles/文件名`。支持 WebP、PNG、JPG 等图片，也支持 HTTPS 图片网址。封面同时用于首页卡片、文章顶部和分享预览。

分类留空时归为“未分类”；封面留空时使用默认山湖图片。正文里的图片也使用 `/img/articles/文件名` 路径。原先的 `# 标题` 与 `标签：...` 写法仍可读取。

写完保存后，双击本文件夹里的 `本地预览.cmd` 检查；确认后双击 `一键发布.cmd`。发布会列出整个仓库的修改，输入 `y` 才会提交并推送。推送后等待 GitHub Actions 部署成功：

https://github.com/P3nd1ng/P3nd1ng.github.io/actions

`articles/` 及所有子文件夹的文章都会公开，未完成的私人草稿请存放在网站文件夹之外。首次在另一台电脑使用时，需要安装 Node.js 22 或以上和 Git，在网站根目录执行一次 `npm ci`。
